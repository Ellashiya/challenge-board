# 챌린지 보드

취업 준비를 위한 매일 할 일·미션 기록 보드입니다. 매일 할 일을 체크하거나 양을 기록하고, 오늘·이번 주 달성률과 연속 달성일을 집계합니다. 따로 미션을 등록해 진행률을 관리할 수 있습니다.

## 기능

- **매일 할 일**: 체크형(했다/안 했다) 또는 숫자형. 숫자형은 시간형(알람 앱 같은 휠 선택기, 시·분 1분 단위)과 개수형(단위·하루 목표)으로 나뉜다. 🎯 미션 탭의 "진행 중"에 미션 카드처럼 보이고 거기서 체크·수정·보관. 추가는 "미션 추가"의 "매일 할 일" 종류나 예시 고르기(홈에도). 홈과 미션 탭이 같은 기록을 씀
- **홈 (슬라이드, 마우스로 끌어 넘기기)**: 앱은 항상 홈에서 시작. 오늘 달성률, 오늘의 미션 기록, 매일 할 일 기록 / 이번 주 항목별 달성 일수·총량, 연속 달성일 🔥, 진행 중 미션
- **달력 (홈·미션 탭)**: 제목 아래 한 주 달력(날마다 달성률 링), 한 달로 펼치기. 날짜를 누르면 홈이 그날 화면이 됨(오늘·어제는 기록, 지난 날은 기록 보기, 다음 날은 할 일 미리 보기)
- **요일·반복**: 기간 미션은 하는 요일(매일·월~일)과 반복(기간 동안 / 매주 반복)을 고른다. 고른 요일에만 오늘의 미션에 나오고 진행률도 그 요일 수로 계산. 매주 반복은 이번 주 기준
- **미션 필터**: [전체][매일][월]…[일] 버튼, 같은 폭으로 가운데 정렬 (켜진 버튼을 다시 누르면 전체로)
- **개수형**: 숫자 칸 옆에 단위 표시, 체크박스를 누르면 하루 몫을 채워 체크
- **미션**: 한 번 끝내는 미션(마감일) 또는 기간·목표 미션(체크형·숫자형), 진행 메모, 진행 중 / 완료 / 중단 / 기한 지남
- **미션 카드 체크박스**: 기간 미션은 그날 했는지(숫자형은 누르면 오늘 한 양 칸이 열림), 한 번 미션은 완료 여부. D-day는 진행률 옆에, 완료·중단·지우기는 ⋯ 메뉴에
- **초과 달성분 제외**: 숫자형은 하루 몫까지만 진행도에 센다 (매일 할 일: 하루 목표, 기간 미션: 목표 ÷ 기간 일수). 하루에 몰아서 해도 완성처럼 보이지 않는다. 실제 양은 그대로 기록
- **설정의 미션 목록**: 완료한 미션(완료 + 진행도 100%), 지운 미션(휴지통 — 되살리기·영구 삭제)
- **지난 미션**: 최근 7일 안에 완료한 미션만 바로 보이고, 7일 지난 완료·중단·보관은 "더 보기"
- **미션 수정**: 이름·날짜·단위·목표를 고칠 수 있다. 미션 종류와 방식, 지금까지의 기록은 그대로 남고, 기간을 줄이면 기간 밖 기록은 진행률에 세지 않는다
- **기록**: 오늘과 어제만 기록 가능 (자정 기준, 한 주는 월요일 시작)
- **백업**: 백업 파일 받기·불러오기, 마지막 백업 후 7일이 지나면 알림
- 휴대폰 화면 우선, 밝은·어두운 화면 자동 전환

## 데이터

기록은 **이 브라우저의 저장소(localStorage)에만** 저장됩니다. 서버로 보내지 않으며, 이 저장소에는 빈 보드만 올라갑니다. 저장 데이터에는 버전 번호가 있어, 데이터 모양이 바뀌어도 이전 백업 파일을 읽을 수 있습니다. 시간형을 넣으며 버전 1 → 2, 요일·반복을 넣으며 2 → 3으로 올렸고(기존 기간 미션은 매일 · 기간 동안으로), 버전 1 데이터는 읽을 때 자동으로 바꿉니다(단위가 "분"·"시간"인 숫자형 → 시간형, 분 단위로 저장).

## 개발 방식: TDD

계산 로직은 테스트를 먼저 쓰고(🔴 실패 확인) → 통과하는 코드를 짠 뒤(🟢) → 다듬는(🔵) 순서로 만들었습니다. 화면(`app.js`)은 계산을 직접 하지 않고 `src/`의 함수만 불러 씁니다.

| 파일 | 내용 | 테스트 |
| --- | --- | --- |
| `src/dates.js` | 날짜 키, 월요일 시작 주, 오늘·어제만 기록 | `test/dates.test.js` |
| `src/items.js` | 달성 판정, 오늘 달성률, 이번 주 요약, 연속 달성일 | `test/items.test.js` |
| `src/missions.js` | 미션 진행률, D-day, 기한 지남 | `test/missions.test.js` |
| `src/store.js` | 항목·미션·기록 변경, 데이터 버전(1 → 2 → 3 변환), 요일·반복 저장, 백업 알림 | `test/store.test.js` |
| `src/missions.js` 요일·반복 | 고른 요일 판단, 매주 반복 진행률, 일정 글자, 필터 | `test/schedule.test.js` |
| `src/wheel.js` | 휠 순환(최대값 다음 최소값), 끌기 속도에 따른 반동 위치 | `test/wheel.test.js` |
| `src/format.js` | 분을 "1시간 25분"으로, 휠용 시·분 나누기 | `test/format.test.js` |

```bash
node --test
```

설치할 것이 없습니다 (Node.js 내장 테스트, Node 24 기준).
